# Urban Brain

Cities: Skylines II 模组 —— AI 驱动的路口信号配时。

个人自用，不公开分发。

## 这是什么

现有的交通 mod 已经把**执行层**做得很好了：[TrafficLightsEnhancement](https://github.com/slyh/Cities2-TrafficLightsEnhancement) 能按实测流量动态调整绿灯长度，[Traffic](https://github.com/krzychu124/Traffic) 能改车道连接和路口优先级。

但它们都不替你决定**这个路口该怎么设计**：用几相位、哪些流向可以并到一起、要不要给左转单独放行。这些配置还得一个路口一个路口手动点。

Urban Brain 做的是上游的方案设计，不是下游的参数微调：

| | 现有 mod | Urban Brain |
|---|---|---|
| 绿灯该延长还是缩短 | ✅ 运行时反馈控制 | 沿用 |
| 这个路口该用几相位、怎么分组 | ❌ 玩家手动设计 | **AI 生成** |
| 全城哪些路口该改 | ❌ 玩家自己找 | **批量扫描** |

最终目标是「城市大脑」，第一期先做路口与信号。

## 状态

所有游戏 API 都来自间接来源（社区数据集 + 参考 mod 源码），每一处猜测都记在 [待验证清单](docs/04-待验证清单.md) 里，按风险排序。**在有游戏的机器上接手时，请先读那份文档。**

已实现（M1–M5，通过 Options 设置页操作）：

- 接管路口信号，写入验证探针（冻结 / 加速）
- 扫描路口几何与实测流量，导出 JSON 快照
- 规则引擎生成配时方案（对向配对 + 按需求比例分配绿灯）
- 调用 Claude API 生成方案并给出理由，规则方案作为基准一并送审
- 相位方案执行：相位循环、黄灯过渡、按「进口 × 转向」放行

未实现：

- M6 游戏内 UI 面板（目前用设置页按钮，功能完整但不好用）
- 指定路口选取（当前以「全城最堵的路口」为操作目标）
- 物理禁转（当前的转向禁止是信号级的永久红灯）

## 架构

三层解耦，采集层和推理层之间用结构化 JSON 快照做稳定契约：

```
┌─────────────────────────────────────────┐
│ L3  推理层（可插拔）                       │
│     RuleAdvisor（对照组） / AiAdvisor      │
├─────────────────────────────────────────┤
│ L2  快照层：结构化城市状态 JSON             │
│     ← 稳定契约，也是天然的调试断点           │
├─────────────────────────────────────────┤
│ L1  采集层：ECS 查询 + 路口几何解析         │
│     Game.Net.LaneFlow / TrafficLights    │
└─────────────────────────────────────────┘
```

快照可以导出成文件带到别的机器上分析 —— 这是在没有游戏的环境下也能推进开发的关键。

配时和转向禁止被统一成同一个概念：相位掩码决定哪些「进口 × 转向」组合放行，某个转向如果不出现在任何相位里就等于被永久禁止。这是交通工程里用信号实现禁左的标准做法，不必改动车道拓扑。

## 使用

编译：

```powershell
.\scripts\build.ps1
```

配置 API key：在游戏用户数据目录下的 `UrbanBrain\` 子目录建 `api-key.txt`，里面只放密钥。同目录放 `model.txt` 可覆盖默认模型。密钥不进设置文件也不进存档。

游戏内进 Options → Urban Brain 操作。

收集日志回传：

```powershell
.\scripts\collect.ps1
```
