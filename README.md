# Urban Brain

Cities: Skylines II 交通管理模组 —— 车道连接、路口规则与信号配时，界面全中文。

个人自用，不公开分发。

## 这是什么

Cities: Skylines II 的交通管理模组，自用。

第一期把 [Traffic](https://github.com/krzychu124/Traffic) 与
[Traffic Lights Enhancement](https://github.com/slyh/Cities2-TrafficLightsEnhancement)
的全部功能集成进同一个模组，界面全中文：

- 车道连接 —— 指定哪条车道能通向哪条
- 路口优先级标志 —— 让行 / 停车 / 优先
- 信号相位自定义 —— 分向放行、左右转专用相位、行人专用相位
- 感应式配时 —— 按实测车流动态调整绿灯时长

之所以要合并而不是各装各的：两者都要接管游戏的 `LaneSystem`，本身存在冲突；
更重要的是，这是在为二期的「城市大脑」打地基 ——
AI 能操作的手段越完整，决策空间才越大。
