# Urban Brain

Cities: Skylines II 模组 —— 把散落在 ECS 各处的模拟数据串成可解释的因果链。

## 这是什么

CS2 的核心痛点是模拟不透明：需求为什么归零、这栋楼为什么被废弃、这条路为什么突然堵了。数据都在游戏里，但散落在几十个互不相关的 system 中，玩家只能靠猜。

Urban Brain 不做数值优化（那个方向已有 [TrafficLightsEnhancement](https://github.com/slyh/Cities2-TrafficLightsEnhancement) 等成熟方案），而是做**跨域因果诊断**：

> 商业区废弃 → 货运到达率低 → 卡车绕行 3.2km → 主干道 17:00–19:00 饱和 → 工业区和住宅区通勤时段完全重叠

这条链上每一环的数据都在游戏里，但没有现有 mod 把它们串起来。

## 架构

三层解耦，采集层和推理层之间用结构化 JSON 快照做稳定契约：

```
┌─────────────────────────────────────────┐
│ L3  推理层（可插拔）                       │
│     LLM API / 规则引擎                    │
├─────────────────────────────────────────┤
│ L2  快照层：结构化城市状态 JSON             │
│     ← 稳定契约，也是天然的调试断点           │
├─────────────────────────────────────────┤
│ L1  采集层：ECS 查询 + 时序聚合             │
│     Game.Net.LaneFlow / Citizens / ...   │
└─────────────────────────────────────────┘
```

即使联网能力受限，L1+L2 仍是一个独立可用的诊断 mod。
