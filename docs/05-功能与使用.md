# 功能与使用

更新：2026-08-28

> 本文依据源码整理（面板构造代码、前端组件、快捷键绑定、本地化条目）。
> **作者没有在游戏里实际操作过**，界面布局的描述属于依代码推断，

---

## 一、三个工具

模组提供三个互相独立的工具，各管一件事：

| 工具 | 解决什么问题 | 入口 |
|---|---|---|
| **车道连接** | 这条进口车道能通向哪些出口车道（能不能左转/掉头） | `Ctrl + R` |
| **优先级标志** | 无信号灯路口谁让谁（让行/停车/优先） | `Ctrl + T` |
| **信号相位** | 有信号灯路口的放行顺序与绿灯时长 | 道路工具 → 道路服务 → 红绿灯 |

前两个来自 Traffic，第三个来自 TLE。三者作用于路口的不同层面，可以叠加使用：
先用车道连接决定「车能去哪」，再用信号相位决定「什么时候能走」。

---

## 二、车道连接（Ctrl + R）

### 用途

默认情况下游戏自动决定车道走向，常见的问题是：三条直行道里有一条被拿去左转、
或者主干道车流被塞进单车道。这个工具让你手动指定每条车道的去向。

### 操作

1. `Ctrl + R` 打开工具，路口上会显示连接点
2. 点击一个**进口**连接点 → 再点击一个**出口**连接点，建立连线
3. 已有连线上再点一次即移除
4. 右键取消当前操作

### 快捷操作（工具激活时）

| 键 | 作用 |
|---|---|
| `Ctrl + 1` | 移除该路口所有车道连接 |
| `Ctrl + 2` | 移除所有掉头连接 |
| `Ctrl + 3` | 移除不安全的连接 |
| `Delete` | 恢复为游戏默认 |

> **不安全连接**指寻路惩罚很高的连线 —— 车辆只在没有别的选择时才会走。

### 限制

- 环岛不支持修改车道连接
- 非默认连接的路口无法升级为环岛
- 不支持双向连线的移除

## 三、优先级标志（Ctrl + T）

### 用途

给**没有信号灯**的路口设置通行规则，相当于现实中的让行标志和停车让行标志。

### 三种标志

| 标志 | 含义 |
|---|---|
| **优先** | 最高优先级，但仍会避让电车 |
| **让行** | 为来自优先级更高道路的车辆让路 |
| **停车** | 在停车线前停车，再为高优先级道路让路 |

### 操作

`Ctrl + T` 打开工具，选中路口后给各个进口分别指定：

| 键 | 作用 |
|---|---|
| `Ctrl + 1` | 设为优先 |
| `Ctrl + 2` | 设为让行 |
| `Ctrl + 3` | 设为停车 |
| `Ctrl + 4` | 重置 |

> 若某个进口显示**虚线轮廓**，表示这里设优先级没有意义 —— 没有其他车辆需要让行。

### 限制

有红绿灯的路口不能设优先级，必须先移除信号灯。

## 四、信号相位（道路工具 → 道路服务 → 红绿灯）

这是功能最深的一块。

### 打开方式

1. 打开**道路工具**
2. 切到**道路服务**标签
3. 选择**红绿灯**
4. 点击任意已有信号灯路口

左上角出现信号灯面板。

### 四种模式

| 模式 | 说明 |
|---|---|
| **原版** | 与游戏默认一致 |
| **分向放行** | 同一时刻只有一个方向放行。适合流量不均衡、冲突严重的路口 |
| **左转专用相位** | 中间车道先专用左转，再进入常规放行 |
| **自定义相位** | 自己定义每个相位放行哪些方向 —— 下一节详述 |

> 「分向放行」和「左转专用相位」只在结构合适的路口出现。
> 有电车轨道等复杂结构的路口选项会变少。
> 目前只完整支持三岔和四岔路口。

### 选项

| 选项 | 说明 |
|---|---|
| **允许红灯转弯** | 红灯时允许右转（左侧通行的地图则是左转） |
| **让行对向车辆** | 转弯时让行对向直行车。仅原版模式可用。注意：司机行为较激进，繁忙路口效果有限 |
| **行人专用相位** | 单独给行人一个全方向停车的过街相位 |
| **行人相位时长** | 0.5–10 倍。仅在启用行人专用相位后出现 |

改完要点**保存**。未保存时面板会提示，切换到别的路口前记得存。

## 五、自定义相位编辑器

选择「自定义相位」模式后，点**打开相位编辑器**。

### 能做什么

自己决定路口有几个相位、每个相位放行哪些方向、每个相位的绿灯时长怎么算。

每个相位一个卡片，可以添加、删除、调整顺序。
点进某个相位后，能逐个进口/逐条车道指定信号状态：

- **通行** — 绿灯
- **让行** — 可通行但需让行
- **禁行** — 红灯

### 相位选项

| 选项 | 说明 |
|---|---|
| 轨道交通优先 | 有电车/火车时优先安排该相位 |
| 公交优先 | 有公交车时优先 |
| 行人优先 | 有行人等待时优先 |
| 与下一相位联动 | 本相位结束后立即接下一相位，不重新排序 |

### 配时参数

这几个参数决定了绿灯时长如何随实测车流变化 ——
**这就是感应式配时**，也是这个模组比原版强的核心。

| 参数 | 范围 | 含义 |
|---|---|---|
| **最短绿灯时长** | 0–30 秒 | 无论多空，至少放这么久 |
| **最长绿灯时长** | 5–300 秒 | 无论多堵，最多放这么久 |
| **目标时长系数** | 0.1–10 | 整体拉长或压缩这个相位的目标时长 |
| **车道占用权重** | — | 排队车辆数对优先级的影响程度 |
| **轮空加权指数** | — | 一个相位越久没轮到，优先级涨得越快。指数越大，涨势越陡 |

### 实时数据

编辑器里能看到该相位的实时状态，用来判断参数调得对不对：

| 项 | 含义 |
|---|---|
| **已计时 / 目标** | 当前相位已经走了多久，目标是多久 |
| **优先级得分** | 综合算出的抢占优先级 |
| **距上次放行(轮)** | 这个相位被跳过了几轮 |
| **车流量** | 实测通过量 |
| **占用车道** | 四个数字：机动车 / 公交 / 轨道 / 人行 |
| **加权等待** | 加权后的等待量 |

还可以**手动控制**，强制指定当前放行哪个相位 —— 用来验证配置是否符合预期。

## 六、快捷键总表

| 键 | 作用 | 生效条件 |
|---|---|---|
| `Ctrl + R` | 开关车道连接工具 | 任意时候 |
| `Ctrl + T` | 开关优先级工具 | 任意时候 |
| 左键 | 应用 | 工具激活时 |
| 右键 | 取消 | 工具激活时 |
| `Ctrl + 1` | 移除全部连接 / 设为优先 | 看当前是哪个工具 |
| `Ctrl + 2` | 移除掉头 / 设为让行 | 同上 |
| `Ctrl + 3` | 移除不安全连接 / 设为停车 | 同上 |
| `Ctrl + 4` | — / 重置优先级 | 优先级工具 |
| `Delete` | 路口恢复默认 | 车道连接工具 |

**信号灯面板默认没有绑定快捷键**，需要在设置里自己指定，或者用界面上的浮动按钮打开。

`Ctrl+1~4` 在两个工具下含义不同，但两个工具是互斥激活的，不会冲突。

## 七、设置页

游戏选项里会出现两个条目：

- **城市大脑 · 车道与优先级** —— 覆盖样式、工具行为、快捷键
- **城市大脑 · 信号配时** —— 新建路口的默认信号模式、面板开关键

其中「信号配时」里的**默认设定**只对**之后新建**的道路生效。
要让已有路口也套用，需要用该页的**强制更新所有节点**按钮 ——
这个操作会重置所有未经手动设定的信号灯，**做之前先存档**。

---

## 八、注意事项

- **不要同时安装 Traffic 或 Traffic Lights Enhancement 原版。**
  三者都要接管游戏的 `LaneSystem`，会冲突
- 车道连接与优先级设置**会写进存档**
- 行人在路口的寻路本身存在游戏侧的问题，不是本模组能解决的
